# 1.1.0 版本說明(App Store「新功能」文案)

## 繁體中文(主要語言)

```
新增 23 種貨幣,涵蓋歐洲、中東、拉丁美洲、東南亞與非洲,總數來到 43 種可選擇的幣別。

選擇貨幣時,幣別名稱會依照你設定的顯示語言(中/英/日/韓)自動切換,不再只顯示中文。

修正「上次更新」時間偶爾顯示不正確的問題。

其他穩定性與效能優化。
```

## English

```
Added 23 more currencies — covering Europe, the Middle East, Latin America, Southeast Asia, and Africa — bringing the total to 43 currencies to choose from.

Currency names in the picker now follow your selected display language (Chinese / English / Japanese / Korean) instead of always showing Chinese.

Fixed an issue where the "last updated" time could occasionally show the wrong time.

Other stability and performance improvements.
```
