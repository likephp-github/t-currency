## Agent skills

### Issue tracker

Issues tracked as GitHub Issues in this repo (likephp-github/t-currency) via the `gh` CLI. External PRs are not treated as a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default label vocabulary (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix) — no repo-specific overrides. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: CONTEXT.md + docs/adr/ at the repo root. See `docs/agents/domain.md`.
